# Checkpoint 1 - Web Development

Projeto com os 10 exercícios de JavaScript do Checkpoint 1.

## Como executar
1. Abra a pasta no VS Code.
2. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server).
3. Abra o Console do navegador (F12 > Console).
4. Selecione um exercício e clique em **Executar exercício**.
5. Responda às perguntas que aparecerem. Os resultados serão exibidos no Console.
